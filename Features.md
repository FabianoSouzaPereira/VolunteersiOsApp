# VolunteersApp - Task List

- [ ] **Cadastro de usuários**  
  - [ ] Incluir dados corriqueiros  
  - [ ] Informações sobre preferências religiosas  
  - [ ] Vivência religiosa (opcional)  

- [ ] **Hierarquia definida**  
  - [ ] Permitir configuração flexível para diferentes segmentos  
  - [ ] Cargos predefinidos: Pastor, Secretary, Leader, Volunteer, Employee, Businessperson, Partner  

- [ ] **Escalas de trabalho**  
  - [ ] Permitir que cada pessoa seja escalada em setores diferentes  
  - [ ] Setores predefinidos: Parking, Reception, Library, Hospitality, Entrance Hall, Kids, Teens  
  - [ ] Permitir atribuição de tarefas individuais  
  - [ ] Voluntários devem informar mensalmente sua disponibilidade  
  - [ ] Campo para justificativas de indisponibilidade  
  - [ ] Notificações para eventos extras e confirmação de participação  

- [ ] **Troca de voluntários**  
  - [ ] Registrar trocas de escala entre voluntários  

- [ ] **Gestão de líderes e setores**  
  - [ ] Cada líder gerencia um setor, mas pode administrar mais de um  
  - [ ] Voluntários podem acumular mais de uma função  

- [ ] **Gestão de Connects**  
  - [ ] Criar grupos de reuniões externas  
  - [ ] Definir casal como líder de cada grupo  
  - [ ] Promover debates sobre temas ministrados nos cultos  
  - [ ] Adaptável para outros segmentos não religiosos  

- [ ] **Calendário integrado**  
  - [ ] Exibir escalas de trabalho  
  - [ ] Incluir eventos extras e reuniões dos Connects  

- [ ] **Sistema de notificações**  
  - [ ] Alertas para mudanças de escala  
  - [ ] Notificações para novos eventos  
  - [ ] Confirmações de presença e avisos importantes  

- [ ] **Área de treinamentos**  
  - [ ] Disponibilizar materiais de capacitação  
  - [ ] Permitir acesso a vídeos e documentos  

- [ ] **Dashboard de gestão**  
  - [ ] Gerar relatórios de participação dos voluntários  
  - [ ] Monitorar presença em eventos  
  - [ ] Avaliação de desempenho dos voluntários  

- [ ] **Check-in e Check-out**  
  - [ ] Registrar entrada e saída dos voluntários nos eventos  

- [ ] **Sistema de feedback**  
  - [ ] Permitir que voluntários e líderes enviem feedback sobre eventos  

- [ ] **Banco de talentos**  
  - [ ] Espaço para voluntários indicarem habilidades adicionais  

- [ ] **Gestão de doações**  
  - [ ] Registro e controle de doações feitas por voluntários e parceiros  

- [ ] **Sistema de comunicação**  
  - [ ] Implementar chat interno ou fóruns para comunicação entre voluntários e líderes
